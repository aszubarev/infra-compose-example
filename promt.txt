Напиши docker-compose.yml файл в котором запускаются следующие компоненты:
- nginx
- keycloak
- oauth2-proxy
- redis
- backend

Цель: реализовать стенд с примером аутентификации через keycloak и механизмом проверки кук сессий, получения токенов,
 проброса токена в backend, его рашифровка и валидация публичным ключем(ами) на backend в тестовых ручках и
 все это визуализировав минимально страницей index.html

Nginx должен выступать точкой входа сетевого трафика.

Keycloak должен запуститься с заранее созданным и настроенными realm и клиентами по возможности.
По моей информации Keycloak можно запустить так, чтобы он прочитав конфиг файл автоматически все настроил.
Соответственно, нужен конфиг файл для Keycloak. Желательно чтобы при старте контейнера создавался тестовый пользователь.
Если через конфиг этого сделать не получится, разрешаю сделать дополнительный контейнер init, который выполнит необходимые операции после старта всех других контейнеров.

Nginx должен проверить аутентификацию через механизм ForwardAuth, который будет делать запрос в oauth2-proxy.
При прохождении аутентификации нужно пропустить запрос c /api (backend) или венуть страницу index.html.
Если пользователь разлогинен, то перенаправь его на страницу входа.

Обязательно задай все важные параметры, например:
* --cookie-refresh (oauth2-proxy)
* --cookie-expire (oauth2-proxy)
* --session-store-type=redis (oauth2-proxy)
* --redis-lock-timeout (oauth2-proxy)
* Client Session Idle (Keycloak)
* SSO Session Max
* и другие важные, которые посчитаешь нужным.

Значения должны быть согласованы и соответствовать тестовому стенду для демонстрации.

Обмен кода аутентификации на access_token + refresh_token желательно сделать по межсервисному внутреннему взаимодействию, а не по внешенму вызову домена keycloack

Используй какой-нибудь тестовый домен чтобы я мог открыть его в браузере. Я пропишу этот домен и все его поддомены в /etc/hosts.
Для keycloak ты можешь использовать субдомен.

Настрой сразу использование ssl. Используй для создания сертификатов инструмент mkcert.

Все пошаговые инструкции для запуска напиши в README.md. Туда же отдельным блоком добавь описание как работает стэнд,
изобрази схемы взаимодействия компонентов.

Задача в том, чтобы стенд запустился одной - тремя командами, с учетом того, что может потребоваться настройка сертификатов и настройка /etc/hosts.
