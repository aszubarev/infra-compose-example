OAuth2 / Keycloak Auth Demo

authenticated

Кто я? (whoami)

Данные пользователя из access_token и из заголовков, которые пробросил oauth2-proxy.

—

Токен (decode)

Сырой access_token и его «расшифровка» (base64-decode header/payload без проверки подписи).

—

Валидация подписи (verify)

Проверка RS256-подписи публичным ключом Keycloak (JWKS), а также iss и exp.

—

Публичные ключи (JWKS)

Ключи Keycloak, которыми подписаны токены.

—

Все запросы к /api/* проходят через nginx auth_request. Если кука сессии истекла — браузер будет перенаправлен на Keycloak для повторного входа.
